# Le Catéchisme

A French-language website for the Catéchisme de l'Église catholique.

## Stack

- SvelteKit 2 + Svelte 5 (runes-only)
- TypeScript, Tailwind CSS 3
- Cloudflare Pages

## Develop

```
npm run dev
```

## Build

```
npm run build
```
